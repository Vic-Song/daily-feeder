# 今日小小投喂 · Daily Feeder

给每天留一点小灵感的手机友好静态小站。无需账号、后端或安装依赖，不记录浏览行为。

- **日期时间**：显示北京时间，时钟每秒更新，日期与卡片统一使用 `Asia/Shanghai` 时区。
- **廊坊天气**：展示当前天气估算、体感温度、当天高低温和降水概率，支持手动刷新。
- **穿衣提示**：根据体感温度、昼夜温差、雨雪和风速生成简单的穿衣与带伞建议。
- **每日卡片**：按北京时间日期展示当天固定的一张常备便签，常备内容轮完后才重复。
- **分类抽签**：只保留“新鲜事、涨知识、轻松一下”三个方向，外加“随便看看”。知识与旧闻合并，笑话与脑洞合并，轻松类优先抽笑话。随机抽签尽量避开最近五张，“随便看看”均衡选择内容类别。
- **便签效果**：淡色纸张、胶带和叠纸；换签时先掀起旧签，再落下新签。支持减少动态效果偏好，动画取消时仍能正常抽卡。
- **跨天刷新**：第二天重新切回页面时，自动展示当天卡片。
- **有出处的内容**：62 条常备便签，包括 12 条科普知识、8 条旧闻、12 条原创笑话和 30 条原有脑洞。知识附来源，旧闻附事件日期，新闻附发布日期与原文链接。
- **手机适配**：小屏幕可直接浏览；支持键盘操作和减少动态效果的系统偏好。
- **个人记录**：每条最多 5000 字，可保存多条、按时间查看历史、搜索和编辑。
- **删除与备份**：删除的记录移入“最近删除”，可恢复；支持导出 JSON 备份，再导入合并。

## 本地预览

直接打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## GitHub Pages

在仓库 **Settings → Pages** 中，将来源设置为 **Deploy from a branch**，选择 **main** 分支和 **/(root)**，保存后等待 GitHub 提供站点地址。无需构建步骤。

## 修改内容

知识、旧闻和笑话保存在 `content.js`；原有脑洞在 `script.js` 的 `originalCards`。每张卡片包含类别、装饰图标、标题、正文和页脚短句。事实类内容还应包含 `sourceName` 与 `sourceUrl`，旧闻包含 `eventDate`。添加或删除常备便签会重新排列每日轮换顺序。

科普来源包括 [NASA](https://science.nasa.gov/)、[NIST](https://www.nist.gov/)、[伦敦自然历史博物馆](https://www.nhm.ac.uk/)、[Python 官方文档](https://docs.python.org/3/faq/general.html)；历史信息使用 CERN、NASA、FIFA、LEGO 等机构的官方资料。正文为简短转述，具体链接写在各条便签中。笑话是虚构娱乐内容。

修改 CSS 或 JavaScript 后，运行 `python3 scripts/version_assets.py` 更新 `index.html` 中的资源版本号，并一起提交。版本号来自文件内容的 SHA-256，避免新页面沿用浏览器缓存中的旧样式或脚本；可用 `python3 scripts/version_assets.py --check` 检查。此过程不涉及浏览器记录数据，也不需要清理用户存储。

## 新闻来源与更新

`scripts/update_news.py` 通过 Python 标准库读取[中国新闻网官方 RSS](https://www.chinanews.com.cn/rss/)的文化、生活、体育、教育和创意五个栏目，每栏最多十条。保留标题、发布时间、原文链接和很短的订阅导语节选，不转载全文。导语去除 HTML 和通讯社电头，明确标注节选，不是 AI 生成的摘要。过滤评论类标题和部分健康建议类生活标题；不做未经来源确认的自动摘要。

GitHub Actions 工作流 `update-news.yml` 每 6 小时尝试更新 `data/news.json`（UTC 00:17、06:17、12:17、18:17），也可在仓库 Actions 页面手动运行。定时触发可能延迟，页面显示实际同步时间。任务通过仓库自带的 `GITHUB_TOKEN` 提交公开新闻数据并请求 Pages 重新构建，无需额外密钥。所有来源全部失败或没有近期标题时保留旧文件，并让任务报错；部分来源失败则明确写入状态。

浏览器每 15 分钟检查同站新闻文件，仅将最近 72 小时内、非未来日期的消息加入抽签。同步较旧或失败时显示相应状态，不把历史新闻重新标成今天。新闻不可用不影响其他便签、天气和个人记录。通过 HTTP 服务器预览才能读取新闻文件，直接打开 HTML 时常备便签仍可用。

## 天气数据

天气来自 [Open-Meteo](https://open-meteo.com/) 的 [Forecast API](https://open-meteo.com/en/docs)，数据使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。当前天气是模型估算，不是实时气象站观测。

默认地点为廊坊市中心（39.52079°N, 116.71471°E），无需浏览器定位权限或 API 密钥。更换城市时修改 `weather.js` 内的经纬度、时区和页面上的城市名称。

天气请求每 30 分钟刷新一次，页面重新切回前台时会检查是否需要更新。浏览器只缓存天气响应，不存用户位置；缓存超过 3 小时、跨天或字段不完整时不再展示。天气接口不可用时，时间和抽卡仍可正常使用。穿衣提示为页面根据天气生成的一般参考，可按个人怕冷怕热程度调整。

除天气请求外，全部字体、样式和内容均使用系统或仓库内资源。

## 个人记录的保存方式

记录使用当前站点、当前浏览器的 `localStorage`（键名 `daily-feeder-journal-v1`），不会上传到 GitHub 或天气服务，也没有账号。历史按记录创建时间倒序显示，以北京时间标注；编辑保留原创建时间。每次保存后才更新存储，存储失败会保留输入文字并提示错误。

删除是可恢复的，不会自动清空“最近删除”。导出的备份包含记录和最近删除；导入同一备份不会重复创建相同 ID 的记录，冲突时保留更新时间较新的版本。导入文件必须符合本站格式且不超过 5 MB。

同一个浏览器的多个标签页会同步刷新列表，但不支持跨浏览器或跨设备自动同步。浏览器清理数据、无痕窗口关闭、站点域名变化都可能使原记录无法访问，请定期导出备份。下载的备份文件也是私人内容，应自行妥善保管。记录以纯文本呈现，不渲染输入中的 HTML。
