# 今日小小投喂 · Daily Feeder

给每天留一点小灵感的手机友好静态小站。无需账号、后端或安装依赖，不记录浏览行为。

- **日期时间**：显示北京时间，时钟每秒更新，日期与卡片统一使用 `Asia/Shanghai` 时区。
- **廊坊天气**：展示当前天气估算、体感温度、当天高低温和降水概率，支持手动刷新。
- **穿衣提示**：根据体感温度、昼夜温差、雨雪和风速生成简单的穿衣与带伞建议。
- **每日卡片**：按北京时间日期，展示当天固定的一张卡片；30 张卡片轮完后才重复。
- **随手再抽**：随机换一张，不会立即抽到同一张。
- **便签效果**：淡色纸张、胶带和叠纸；换签时先掀起旧签，再落下新签。支持减少动态效果偏好，动画取消时仍能正常抽卡。
- **跨天刷新**：第二天重新切回页面时，自动展示当天卡片。
- **五类原创内容**：3D 打印灵感、编程脑洞、喜剧脑洞、足球小选择、随手一问。
- **手机适配**：小屏幕可直接浏览；支持键盘操作和减少动态效果的系统偏好。
- **个人记录**：每条最多 5000 字，可保存多条、按时间查看历史、搜索和编辑。
- **删除与备份**：删除的记录移入“最近删除”，可恢复；支持导出 JSON 备份，再导入合并。

## 本地预览

直接打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## GitHub Pages

在仓库 **Settings → Pages** 中，将来源设置为 **Deploy from a branch**，选择 **main** 分支和 **/(root)**，保存后等待 GitHub 提供站点地址。无需构建步骤。

## 修改内容

修改 `script.js` 顶部的 `cards` 数组。每张卡片包含类别、装饰图标、标题、正文和页脚短句。添加或删除卡片会重新排列每日轮换顺序。

## 天气数据

天气来自 [Open-Meteo](https://open-meteo.com/) 的 [Forecast API](https://open-meteo.com/en/docs)，数据使用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。当前天气是模型估算，不是实时气象站观测。

默认地点为廊坊市中心（39.52079°N, 116.71471°E），无需浏览器定位权限或 API 密钥。更换城市时修改 `weather.js` 内的经纬度、时区和页面上的城市名称。

天气请求每 30 分钟刷新一次，页面重新切回前台时会检查是否需要更新。浏览器只缓存天气响应，不存用户位置；缓存超过 3 小时、跨天或字段不完整时不再展示。天气接口不可用时，时间和抽卡仍可正常使用。穿衣提示为页面根据天气生成的一般参考，可按个人怕冷怕热程度调整。

除天气请求外，全部字体、样式和内容均使用系统或仓库内资源。

## 个人记录的保存方式

记录使用当前站点、当前浏览器的 `localStorage`（键名 `daily-feeder-journal-v1`），不会上传到 GitHub 或天气服务，也没有账号。历史按记录创建时间倒序显示，以北京时间标注；编辑保留原创建时间。每次保存后才更新存储，存储失败会保留输入文字并提示错误。

删除是可恢复的，不会自动清空“最近删除”。导出的备份包含记录和最近删除；导入同一备份不会重复创建相同 ID 的记录，冲突时保留更新时间较新的版本。导入文件必须符合本站格式且不超过 5 MB。

同一个浏览器的多个标签页会同步刷新列表，但不支持跨浏览器或跨设备自动同步。浏览器清理数据、无痕窗口关闭、站点域名变化都可能使原记录无法访问，请定期导出备份。下载的备份文件也是私人内容，应自行妥善保管。记录以纯文本呈现，不渲染输入中的 HTML。
